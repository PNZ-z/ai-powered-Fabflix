## 1. 目标

在进入 B-① **之前**，用可复现的评测回答一个问题：

> **用户侧的"电影检索 + 推荐"应该采用"电影卡片 + embedding 语义检索"（A）、"结构化工具 / 工具调用路由"（B），还是两者混合？**

输出 = **决策备忘录**（本文件 §7）+ 两份带实测数字的评测报告。**不交付任何面向用户的功能。**

**范围前提（用户已批准 D-1）**：用户问的是**电影**，与项目开发过程无关。**开发文档不是用户语料** —— `docs/**`、`README.md` 不得被切分、embedding、索引或作为用户问答语料。

**三条影响评测设计的硬事实**（两份子计划都必须遵守）：

1. 任何"1960s–2000 + 评分门槛"的查询**必然空结果**（该区间无评分行）→ 不得作为正样本，且必须由 `EMPTY_RESULT` + `coverage.rating_coverage_from=2001` 解释，而不是"没有这类电影"。
2. 类型枚举必须**由 DB 派生**（`SELECT DISTINCT name FROM genres ORDER BY name` → 当前 56 个），不得写死；重复行必须 `DISTINCT`；`Sci-Fi`/`Science Fiction` 的规范化属服务端别名决策。
3. `id` 只能当不透明主键使用；旧文档"`tt` 编号"的表述已修正。

### 3.2 指标分工：D8 门（A 的 `recall@5`）vs 跨路线比较（任务级成功）

> **2026-11-09 已裁定（`OPEN-U2` 关闭）**：两个口径**不能互相替代**，各有用途：

| 用途 | 指标 | 说明 |

## 4. 决策标准（两条路线逐条打表，memo 用）

| 维度 | 权重（建议） | A（卡片 embedding） | B（工具/路由） |
| --- | --- | --- | --- |
| 任务级成功率 / D8 | 高 | **任务级 = `recall@5`，实测 0.4833 / 0.4167 → D8 FAIL**（并集 53.3% 仍 <80%）；片名类 0.867–1.000，filter 0.10–0.45，similar 0.20 | 见 B1.5b 报告（**未开始**） |
| 延迟（p50/p95，含冷启动） | 高 | 1 次 embedding（**实测** 热 p50 **35–59 ms**；冷启动 **1.37–2.37 s**；`qwen3` 已测） | 1 次 chat（热 0.38–1.94 s / 冷 **39.10 s**）+ 工具 SQL（未单独计时） |
| 实现复杂度 | 中 | 卡片构建 + 索引 + 重建 + 模型选择 | 工具实现 + **服务端校验/枚举映射/覆盖检查/渲染/前置拒绝** + 路由 |
| 数据新鲜度 | 中 | 需重建（新片/改模板） | 实时 |
| 可解释性 | 中高 | 弱（相似度不可解释） | 强（字段交集 + `applied_filters`） |
| 认证/安全边界 | 高 | 索引是 DB 副本，需与登录边界一致；**不新增网络端点** | 复用现有只读查询与过滤器；**本期不发布 MCP 端点**（D-6）→ 若引入须另立鉴权 issue |
| 中文能力风险 | 高 | **实测：不是头号风险**——`qwen3` 中文译名 **3/3**、`bge-m3` 1/3；真正的失败原因是**结构化约束在 dense 短文本里没有表示** | 低（槽位结构化），但**枚举语言**已实测出错 → 必须服务端映射 |
| 一次构建成本 | 中 | **实测**：4 组合合计 **1,762 s ≈ 29.4 min**（单组合 5.3–8.9 min）、tokens ≈ 3.24 M、向量 **82.4 MiB/组合** | 0 构建；每次 chat 约 598 tokens prompt（5 工具） |
| CI 可测性 | 中 | 需真实端点 | 工具层可单测；路由需真实端点 |

**允许混合**：`find_similar_movies` 内部可用向量实现，对外仍是工具契约；此时 A 的构建成本与新鲜度问题回到台面，memo 必须写明。

**决策规则（先定门槛，再看数据，避免"数据出来再挑标准"）**：

1. A 路线未达 **D8 的 `recall@5` / top-5 ≥80%**（判定只看此数，**任务级成功率为次要**）→ A 不得单独作为交付架构；**（2026-11-09 实测：0.4833 / 0.4167 → 本条已触发，A 不得单独交付）**；
2. B 路线纯 LLM 路由**不得**交付（D-9 已批准）；只评估"确定性路由 + 受控填充"形态；
3. 若两者各自只覆盖部分意图（例如 A 擅长"相似/模糊"，B 擅长"精确筛选"），memo 应明确给出**混合**方案与各自承担的子集，而不是二选一凑结论。
