### 2.1 评测方法论（统计与判定）

- **点估计门槛 vs Wilson 区间**：门槛判定按**点估计**（25/30 = 83.3% < 90% → FAIL），而 Wilson 区间只用于表达精度。25/30 的区间上界 92.7% > 90%，**不能**据此说“实际可能达标”；反过来 30/30 的区间下界 88.6% < 90%，也**不能**说“已有 95% 置信达标”。对应文件：报告 §6.4、计划 §7.2。学习价值：避免“区间跨过门槛就当通过/不通过”的常见误用。
- **分母敏感性必须先**定义成员**，再做移除**：移除用例时要同时移除它的成功/失败计数，否则“去探针”口径会凭空变差（本批实际踩到，见 §1.3 第 12 项）。对应文件：报告 §3.1/§3.2、计划 §7.1。学习价值：口径文档化（成员显式）本身就是可审计性的一部分。
- **严格任务级判分（all-gates）**：`tools_ok ∧ slots_ok ∧ schema_ok ∧ behavior_ok ∧ grounding_ok ∧ acceptable_hit` 全真才算成功。`B27` 的 `acceptable_hit = true` 但 `slots_ok = false` → 失败。对应文件：报告 §4.1 第 5 条。学习价值：区分“检索碰巧命中”和“任务被正确完成”。
- **盲测（blind holdout）的可审计三件套**：①首次运行严格晚于冻结；②冻结用外部可核对的值（`sha256` + `git hash-object -w` blob + `mtime`）；③被测对象（`tool_eval.py` 等）对该基线的 **空 diff**。对应文件：报告 §2、计划 §4.3。学习价值：盲测不是“我觉得没看过”，而是可被第三方按时间线核对的证据链。

### 2.2 评测运行机制（缓存与解析器）

- **缓存状态机 `absent` / `loaded` / `replay`**：冷跑必须 `rm -f` 独立缓存路径并断言 `cache_state_at_load = "absent"`，热跑同路径 `loaded`，回放用 `--replay-resolver <产物>` 且 `model_calls = 0`。对应文件：报告 §3.3、§7.1。学习价值：不加隔离的“冷跑”很容易实际是热跑，主数字会静默失真。
- **冷/热一致性 ≠ 独立测量**：热跑/回放的用途是证明**缓存一致性**（逐例 `task_success` + `chosen_movie_id` 相同），不能拿来当第二个测量样本。对应文件：报告 §3.3。学习价值：避免把复算结果当成独立证据重复计数。
- **解析器的“LLM 候选 + 目录校验”链路**：`llm_candidates` → `catalog_verified`（`match = exact`）→ `chosen_movie_id`；记录 `request_sha256`/`prompt_sha256`/`cache` 便于复算。对应文件：报告 §3.5、产物 `blind-G1T-cold.json` 的 `records[].resolver`。学习价值：把“模型输出”与“被采用的实体”分开追踪，是 `wrong_movie_rate` 这类指标可解释的前提。

### 2.3 领域/数据语义（本次失败暴露的真实缺口）

- **种子类型 vs 文本显式约束的求交语义**：`B26` 里执行器把种子自身类型（`{Family, Horror}`）与文本显式约束（`Horror` + 1991–1992）**同时**作为 AND，得到空集（预期 22 行）。这是**执行语义**决策，不是解析或路由问题。对应文件：报告 §4.1 第 4 条。学习价值：相似推荐的“约束收窄”策略必须显式定义，否则会静默产生空结果。
- **canonical genre 词形归一与同义歧义**：`musicals → Musical`（别名表）与标注口径 `Music` 冲突（`R-1`，全库 619 vs 139 是**两个不同目录类型**，不是同义写法）；`documentaries` 未映射到 `Documentary`（`B27`）。对应文件：报告 §5.1、§4.1 第 5 条；`docs/ai/aliases/genre-aliases.json`。学习价值：别名表的“映射方向”与“同义词 vs 不同类”的判断会直接决定判分结果，必须由决策者裁定而非实现者顺手决定。
- **越界请求（out-of-scope）的拒绝边界**：票房/奖项/发行公司/配乐作者都不在目录字段内，必须**拒绝且不调工具**；实际调用 `search_movies_by_title` 属 `under_refusal`。对应文件：报告 §4.1 第 1 条。学习价值：拒绝类用例的判分不仅看“工具对不对”，还看“该不该调用工具”。
